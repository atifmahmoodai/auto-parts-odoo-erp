# Auto Parts Odoo ERP

This repo is a project brief, not the client's private code. It records what the buyer asked for so the build can be scoped against a real paid post.

## What this repo is about

An auto-parts dealership posted a fixed $2,000 project for an Odoo ERP covering sales, purchase, warehouse, and accounting. Expected timeline 4–6 weeks, expert level.

## Source post

https://www.upwork.com/freelance-jobs/apply/Odoo-Developer_~022040764200265767828/

## Client requirements

- Odoo Community or Enterprise, configured for an auto-parts dealer.
- Modules: sales, purchase, inventory and warehouse, accounting and invoicing, CRM, vendors.
- Multi-location stock, barcode if needed, dashboards, data migration, user training, documentation, at least 1 month of support.
- Python and PostgreSQL. Custom modules. Parts or retail inventory experience is a plus.
- Proposal: similar Odoo work, approach, timeline, cost split, workflow suggestions.

## Notes

- Requirements are taken from the public job post. They are not a signed contract.
- Posts can close or change. Check the source link before bidding.
